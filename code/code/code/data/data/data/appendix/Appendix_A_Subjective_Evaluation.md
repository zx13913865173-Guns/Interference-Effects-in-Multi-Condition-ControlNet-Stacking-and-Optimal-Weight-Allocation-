# Appendix A: Subjective Evaluation Instruction

You will see images generated by an AI system under various combinations of ControlNet conditions. For each image, rate how well the image integrates both condition inputs without visible conflict. Use the following scale:

1 – Severe conflict: conditions clearly override each other
2 – Moderate conflict
3 – Acceptable integration with minor artefacts
4 – Good integration
5 – Excellent seamless integration

## Rater characteristics

### Graduate raters
- N = 15
- 6 male, 9 female
- Age: M = 23.6, SD = 1.5, range 22–28
- AI experience: M = 1.6 years, range 1–3
- Written informed consent obtained
- Not compensated

### Professional AI artists
- N = 10
- 4 commercial AI artists, 3 independent artists with exhibition records, 3 AI art tool developers
- At least 3 years of ControlNet experience
- 200 stratified images
- Fleiss Kappa = 0.78
- ICC(2,1) = 0.91
