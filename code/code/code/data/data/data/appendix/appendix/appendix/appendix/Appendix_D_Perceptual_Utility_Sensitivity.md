# Appendix D: Perceptual Utility Sensitivity Analysis

The primary analysis used equal λ weights (0.2 each). A sensitivity analysis used professional AI artist ranking-derived weights:

- λ1 = 0.25
- λ2 = 0.25
- λ3 = 0.20
- λ4 = 0.15
- λ5 = 0.15

The optimal ratios shifted by less than 2 percentage points in all condition pairs. The professional artist preference remained consistent.

Full results are available in `data/utility_sensitivity.csv`.
